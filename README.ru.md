# Wipeport — нативный порт WipEout Omega Collection для Linux

[English](README.md) · **Русский**

Wipeport запускает *WipEout Omega Collection* для PlayStation 4 (CUSA05670, обновление 1.07) на
ПК с Linux x86-64 как нативную программу — на мониторе или в VR-шлеме для ПК:

- оригинальный исполняемый файл игры (x86-64) выполняется прямо на процессоре, без эмуляции и
  трансляции инструкций; системные библиотеки PS4, которые вызывает игра, заменяет небольшой
  runtime, написанный под эту игру;
- графика транслируется в Vulkan рендерером на основе
  [shadPS4](https://github.com/shadps4-emu/shadPS4);
- вместо PlayStation VR работает любой шлем через OpenXR (SteamVR), библиотеки PS VR взяты из
  [AstroQuest](https://github.com/bigmak94/AstroQuest).

Wipeport — форк [bloodborne_pc](https://github.com/deadinside28/bloodborne_pc), нативного порта
Bloodborne от deadinside28: вся его история — история этого репозитория. Поддержка Bloodborne
убрана, когда проект стал портом только WipEout. Кто сделал то, из чего собран порт:
[CREDITS.md](CREDITS.md), [CONTRIBUTORS.md](CONTRIBUTORS.md).

> **Файлы игры не входят в проект.** Нужен собственный дамп WipEout Omega Collection с
> обновлением 1.07. Проект не связан с Sony Interactive Entertainment.

**Состояние: экспериментальное.** Игра запускается, гонки идут со звуком и геймпадом, в шлеме
через SteamVR — до 120 к/с. Проверено на одной машине: Linux, AMD Radeon RX 6800 XT,
Mesa/RADV, SteamVR с Meta Quest 2.

## Возможности

- **Нативное выполнение.** eboot заранее превращается в образ памяти, в который слинкованы
  собственные модули игры; загрузчик на C отображает его и передаёт управление игре.
- **Любое разрешение и частота кадров на мониторе.** Игра берёт размер сцены из видеорежима,
  который сообщает система: порт сообщает выбранный размер (`render_res`) и масштабирует
  картинку под окно. Частота кадров по умолчанию не ограничена (логика игры следует за временем
  кадра), ограничение — `fps_limit`.
- **VR на ПК.** Режим PS VR игры в шлеме OpenXR: отслеживание головы, оба глаза, IPD шлема для
  самой игры, зеркало левого глаза в окне. Патчи в коде игры (найдены дизассемблированием,
  [docs/GAME_CODE.md](docs/GAME_CODE.md)) делают его лучше, чем на PS4:
  - **120 к/с** вместо 60 с репроекцией до 120 на PS VR;
  - **любое разрешение глаза** (PS4 рисует 1344×1512 на глаз, PS4 Pro — 1440×1620);
  - **без динамического разрешения**: игра больше не снижает разрешение глаз под нагрузкой.
- **Лаунчер на GTK4** со страницей VR, модами и сторонними патчами.
- **Моды**: файлы поверх `data/` игры и замена архивов `.psarc`, с порядком загрузки, без
  изменения папки игры ([docs/MODS.md](docs/MODS.md)).

## Требования

- Linux x86-64, видеокарта с Vulkan 1.3.
- Ваша расшифрованная игра: папка `CUSA05670` (eboot.bin, sce_module, sce_sys, архивы `.psarc`)
  с обновлением 1.07, скопированным поверх базовой игры. Лаунчер и `run.sh` проверяют
  исполняемый файл и сообщают, если обновления нет (`WOC_SKIP_GAME_CHECK=1` отключает проверку).
  Другие регионы пока не проверены: их исполняемый файл 1.07 должен совпадать.
  Файлы `.pkg` распаковывает PkgTool из [LibOrbisPkg](https://github.com/maxton/LibOrbisPkg)
  (в Linux может понадобиться `DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1`).
- Для VR: SteamVR (или другой OpenXR runtime) и шлем.
- Для сборки: GCC, CMake, Ninja, Python 3, glslang, SDL3, заголовки Vulkan, загрузчик OpenXR и
  библиотеки из `shell.nix`. С [Nix](https://nixos.org) всё берётся из `shell.nix`.

## Сборка и запуск

```bash
git clone --recursive https://github.com/shipa-2/Wipeport.git && cd Wipeport
bash build.sh                              # out/woc-probe и out/gpu/libwocgpu.so
WOC_GAME_DIR=/путь/к/CUSA05670 bash run.sh
```

или лаунчер (выбрать папку игры, настройки, *Запустить*):

```bash
bash launcher/woc-launcher.sh              # launcher/install-desktop.sh добавляет его в меню
```

По умолчанию папка игры ищется рядом с репозиторием (`../CUSA05670`). Сохранения и кеш шейдеров
лежат в `user/`, настройки — в `wipeport.ini`.

### Настройки (`wipeport.ini`, лаунчер или переменные окружения)

| Настройка | Переменная | Значение |
|---|---|---|
| `render_res=2560x1440` | `WOC_INTERNAL_WIDTH/HEIGHT` | Разрешение рендера на мониторе; пусто — 1920×1080, как на PS4. До 3839 пикселей по ширине; с 3840 игра включает свой 4K-режим, который рисует половину ширины |
| `fps_limit=144` | `WOC_FPS_LIMIT` | Ограничение кадров на мониторе; 0 или пусто — без ограничения |
| `vr_scale=2` | `WOC_VR_SCALE` | Разрешение глаза: 960×1080 × масштаб (2 = 1920×2160); пусто — 1.4 игры |
| `vr_fps=120` | `WOC_VR_FPS` | 60 (как на PS VR) или 120 |
| `vr_dynres=0` | `WOC_VR_DYNRES` | 1 — динамическое разрешение игры, 0 — всегда полный размер |
| | `SHADPS4_VR=1` / `0` | Шлем включён / выключен (не задано — если OpenXR runtime видит шлем) |
| | `SHADPS4_OPENXR=0` | Без OpenXR: вместе с `SHADPS4_VR=1` — VR-режим игры без шлема, для проверок |

Подробно о VR — шлемы, разрешение глаза для Quest 2 и других, IPD, как кадры попадают в шлем:
[docs/VR.md](docs/VR.md).

## Устройство

| Часть | Что это |
|---|---|
| `scripts/` | Подготовка заранее: eboot в образ памяти, линковка модулей игры, компилятор патчей (`patches.py`, встроенные патчи — `wipeout_patches.py`), моды (`mods.py`) |
| `src/` | Загрузчик (`probe.c`) и runtime (`runtime_*.c`): память, потоки, синхронизация, файлы, звук (ATRAC9), геймпад, сохранения |
| `gpu/` | Библиотека рендерера: видеоядро и рекомпилятор шейдеров shadPS4 (вендорены, `gpu/VENDOR.txt`) с изменениями порта (помечены `wocport:`), библиотеки PS VR и OpenXR-хост из AstroQuest, прослойки к runtime |
| `launcher/`, `packaging/` | Лаунчер GTK4; пакет Nix и AppImage |
| `tools/` | Инструменты разработчика: поиск и дизассемблирование в eboot, чтение `.psarc`, скрипты RenderDoc, автоматические запуски |
| `tests/` | Тесты загрузчика, runtime, патчей и модов |
| `docs/` | Заметки: [VR](docs/VR.md), [код игры](docs/GAME_CODE.md), [моды](docs/MODS.md), [импорты](docs/WIPEOUT_IMPORTS.md); устройство рендерера из bloodborne_pc ([docs/README.md](docs/README.md)) |

Тесты: `bash build.sh --test` и `python3 -m unittest discover -s tests`.

## Известные проблемы

- С ширины 3840 пикселей игра включает свой шахматный 4K-режим; место в коде, где она это
  решает, пока не найдено, поэтому нативного 4K пока нет.
- Режим PS4 Pro (`WOC_NEO=1`) рисует искажённую картинку.
- Нет сетевой игры (PSN): таблиц рекордов, мультиплеера и трофеев.
- Временные апскейлеры (FSR 3.1/4, DLSS) и меню поверх игры пришли из bloodborne_pc и сделаны
  под кадр Bloodborne; под WipEout они пока не адаптированы.
- Скрипт AppImage унаследован и с этой игрой ещё не проверен.
